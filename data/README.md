# Data

## Banknote Authentication

Primary real dataset: UCI Banknote Authentication.

- Source: UCI Machine Learning Repository
- DOI: `10.24432/C55P57`
- License: CC BY 4.0
- Instances: 1,372
- Features: 4 continuous features extracted from banknote images
- Target: binary class label

Citation:

Lohweg, V. (2012). Banknote Authentication [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55P57

The project includes `banknote_authentication.csv` so experiments are reproducible without repeatedly downloading data.
